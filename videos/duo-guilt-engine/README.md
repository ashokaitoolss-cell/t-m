# Duo — the guilt engine

A 60.5 s vertical (1080×1920, 30 fps) explainer on how Duolingo turned Duo the owl into
a growth engine, built in [HyperFrames](https://github.com/heygen-com/hyperframes) to the
*2.5D Paper-Halftone Explainer* style guide. `BRIEF.md` holds the intent and
`STORYBOARD.md` the approved scene-by-scene plan.

## How it's put together

| Layer | Source | Notes |
| --- | --- | --- |
| Timeline | `index.html` (generated by `scripts/build-timeline.mjs`) | 30 scene clips, one caption track, the voiceover, SFX lanes, the music bed |
| Scenes | `data/scenes.mjs` → `scripts/build-scenes.mjs` → `compositions/frames/*.html` | Each spoken phrase is its own sub-composition |
| Captions | same generator → `compositions/captions.html` | Instrument Serif, 1–3 words, word-timed |
| Motion | `assets/vendor/scenekit.js` | Stepped camera/parallax/puppets at 15 drawings/s, seeded wiggle, glints |
| Plates | Higgsfield, listed in `data/plates.json` | `scripts/fetch-plates.mjs` downloads, `scripts/prep-plates.py` builds the planes |
| Sound | `data/sfx.mjs`, `assets/sfx/`, `assets/audio/bed.wav` | One effect per visual event; the bed is carved under the voice |
| Print texture | `scripts/finish.py` | Halftone, paper, grain, edge blur, RGB split, vignette; −14 LUFS |

Edit `data/scenes.mjs` or `data/sfx.mjs` and rebuild; the generated HTML is not
hand-edited.

## Build

```bash
npm install
scripts/build.sh --no-render   # fetch + prep plates, generate compositions, carve, lint
npm run dev                    # open the timeline in HyperFrames Studio
scripts/build.sh               # full render: renders/duo-guilt-engine.mp4
```

Needs Node 22, Python 3 with `opencv-python-headless numpy scipy`, and ffmpeg.

## Placeholders

- `assets/sfx/*.wav` and `assets/audio/bed.wav` are synthesized by `scripts/synth-sfx.py`
  as stand-ins for the user's SFX library; replace a file (same name) to swap a sound.
- Any plate missing from `assets/plates/` renders as a labelled placeholder.
